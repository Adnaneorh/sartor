# sartor.

Swipe-based job hunting for Canada with truthful resume tailoring.

Monorepo: Next.js app at the root (Vercel), Python worker in `worker/` from
Phase 2 (Railway). Start with [CLAUDE.md](CLAUDE.md), then `docs/PRD.md` and
`docs/ROADMAP.md`.

## Local dev

```bash
npm install
npm run dev   # http://localhost:3000
```

Environment variables: copy `.env.example` to `.env.local` and follow the
where-to-get comments. Never commit real values.
